# Dados locais

O conteúdo de `data/raw` e `data/generated` é ignorado pelo Git.

- `raw/olist/v1`: nove CSVs Olist e `_manifest.json`;
- `generated`: eventos sintéticos explicitamente marcados;
- `local`: tabelas e checkpoints da execução local futura;
- `sample`: fixtures pequenas que podem ser versionadas quando não violarem licença.

Nenhum dataset de terceiros deve ser commitado sem uma revisão explícita de licença.
